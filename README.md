# ⚖️ Landing Page — Souza & Associados Advocacia

Landing page demonstrativa desenvolvida para um escritório de advocacia fictício, com foco em apresentação institucional, áreas de atuação e captação de contato para consultas jurídicas.

> Projeto educacional, desenvolvido para fins de estudo e portfólio.

## 🔗 Demo

Abra o arquivo [`index.html`](./index.html) no navegador ou publique com GitHub Pages para visualizar a página no ar.

## 📋 Sobre o projeto

A página apresenta a estrutura típica de uma landing page institucional para o setor jurídico, incluindo:

- **Header fixo** com navegação por âncoras e menu responsivo (hambúrguer no mobile)
- **Hero section** com chamada principal e botões de ação (CTA)
- **Áreas de atuação**: Direito Civil, Trabalhista, Empresarial e de Família
- **Sobre nós**: valores do escritório e diferenciais de atendimento
- **Estatísticas**: anos de experiência, casos resolvidos, clientes atendidos e satisfação
- **Depoimentos** de clientes
- **Seção de contato/CTA** para agendamento de consulta
- **Footer** com navegação, contato e dados institucionais

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização (arquivo `css/style.css`)
- **JavaScript** (vanilla) — controle do menu mobile (`js/menu.js`)
- **Google Fonts** — [Inter](https://fonts.google.com/specimen/Inter) e [Playfair Display](https://fonts.google.com/specimen/Playfair+Display)
- **SVG** — ícones e ilustrações personalizadas

## 🚀 Como executar localmente

Por ser um projeto estático (HTML, CSS e JS puros), não há dependências para instalar.

1. Clone o repositório:
   ```bash
   git clone https://github.com/ZovicoDev/landing-page-advocacia.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd landing-page-advocacia
   ```
3. Abra o arquivo `index.html` diretamente no navegador, ou utilize uma extensão como o **Live Server** (VS Code) para servir a página localmente com recarregamento automático.
